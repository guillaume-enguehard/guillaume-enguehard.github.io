# DORON — submission files

Files for the submission of DORON, an abstract wooden game for two players by Guillaume Enguehard. This branch is not part of the website.

- [DORON_submission.pdf](DORON_submission.pdf): sell sheet, rules (2 pages) and tactics guide (4 pages)
- [DORON_concept.jpg](DORON_concept.jpg): concept image created with the help of AI; final design and materials to be defined with the publisher

Play online: https://guillaume-enguehard.github.io/games/doron/play/
